# Introduction
Relic is a web server framework for Dart, built by the [Serverpod](https://serverpod.dev) team. It grew out of [Shelf](https://pub.dev/packages/shelf), and it keeps Shelf's model of handlers that turn requests into responses and middleware that wraps handlers.

#### Why Relic?

Serverpod needed typed headers, a router that stays fast as routes are added, and WebSockets in the core. Those changes reach into the request and response types themselves, so Relic became a framework of its own rather than a set of packages on top of Shelf.

## Features

## How Relic differs from Shelf

If you know Shelf, most of Relic will look familiar. These are the places where it works differently:

| Area | Shelf | Relic |
|------|-------|-------|
| Headers | Strings in a map | Typed accessors that validate values |
| Routing | `shelf_router`, which tries routes in order | A built-in router on a trie, matched segment by segment |
| WebSockets | The `shelf_web_socket` package | Built in |
| Path parameters | Strings, passed as extra handler arguments | Read from the request by symbol, with typed accessors |
| Static files | The `shelf_static` package | `StaticHandler`, with cache busting and ETags |
| Hijacking | A thrown `HijackException` | A returned `Hijack` or `WebSocketUpgrade` result |
| Request state | A `Map<String, Object>` context | Typed context properties |
| Body | Content and encoding set separately | One `Body` that carries content, type and encoding |
